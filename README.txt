LGC VISION — site vitrine statique
===================================

Fichiers :
- index.html : page principale
- styles.css : design responsive
- script.js : menu mobile et formulaire
- mentions-legales.html : page légale à compléter
- assets/ : logo et photos fournies

Mise en ligne :
1. Envoyer tout le contenu du dossier sur l'hébergement de lgc-vision.fr.
2. Dans script.js, remplacer CONTACT_EMAIL = 'A_CONFIGURER' par l'adresse e-mail réelle de réception.
   Le formulaire ouvrira alors le logiciel de messagerie du visiteur avec le message prérempli.
   Pour un formulaire qui envoie sans logiciel de messagerie, connecter un service de formulaire
   ou un endpoint serveur et modifier script.js.
3. Compléter mentions-legales.html (raison sociale, adresse, SIRET, hébergeur, responsable de publication).
4. Vérifier les coordonnées exactes du point sur la carte : le repère actuel est indicatif, centré sur le secteur Saint-Bernard à Vallauris.
5. Tester sur mobile et ordinateur, puis activer HTTPS pour lgc-vision.fr.

Note :
- La carte utilise OpenStreetMap dans une iframe et nécessite une connexion internet.
- Le formulaire est une version statique côté navigateur : aucune donnée n'est envoyée à un serveur par défaut.
- Les horaires de diffusion, tarifs, coordonnées de contact et statistiques de trafic n'ont pas été inventés.
